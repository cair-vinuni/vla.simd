# Offline checkpoint conversion. None of this is needed to run a converted
# checkpoint, so the robot never carries it.
#
#   uv venv .venv-convert
#   uv pip install --python .venv-convert -r tools/requirements-convert.txt
#
# This file covers the torch-free path: SmolVLA's convert_hf_safetensors.py and
# convert_tokenizer.py, which read the checkpoint in numpy and run on a Pi.
#
# It cannot also host Octo's convert_t5_tokenizer.py: that needs transformers
# 4.x, which caps huggingface-hub below the 1.0 this path requires. It runs in
# .venv-octo, which already pins a compatible pair.
#
# The torch converters (ACT, IMPACT, Diffusion, SmolVLA finetunes) must run in
# the environment their checkpoint was TRAINED in, not this one - install
# lerobot there and run them there. TurboVLA needs its own: torch plus
# transformers >=4.57,<5, and deliberately not timm or lerobot. Octo needs a
# frozen JAX stack, see tools/octo/pyproject.toml.

numpy>=2.1,<3
safetensors>=0.6,<1
huggingface_hub>=1.0,<2
